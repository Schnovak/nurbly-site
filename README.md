# nurbly-site

One page: the privacy policy for the Nürbly Android app, live at
<https://schnovak.github.io/nurbly-site/>.

Google Play will not publish an app without a public privacy policy URL, and
it re-checks that the URL still loads after the app is live. A dead link is
treated as a policy violation, which is why this is on GitHub Pages rather
than behind the Cloudflare tunnel on a laptop that reboots.

`index.html` is a copy. The source of truth is `play/privacy/index.html` in
the Nürbly repo at `~/projects/android/nurbly`. Edit it there, copy it here,
push, and Pages redeploys in about a minute.
